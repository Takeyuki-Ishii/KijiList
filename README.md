# 期限付きタスク管理 Webアプリケーション(仮)

検索・ソート・フィルター・ページネーションが高度に連動する、Spring Bootで構築した期限付きタスク管理システム（仮）です。

## 🌟 本システムの一番のこだわり（アピールポイント）
「検索 × ソート（期限・重要度） × 状態フィルター × ページネーション」の**完全連動およびURLパラメータの状態維持**にこだわって開発しました。
完了ボタンの押下や、入力値バリデーションエラーが発生した場合でも、ユーザーが選択していた表示条件（ページ番号や検索ワードなど）が崩れることなく、ストレスのない操作性を実現しています。

## 🚀 主な機能
1. **タスク一覧表示**：期限が近い順 / 重要度順に自動ソート
2. **高度な条件絞り込み＆検索**：
    - キーワード検索（タスク名の部分一致）
    - 完了状態フィルター（すべて / 未完了のみ / 完了のみ）
    - ソート切り替え（期限順 / 重要度順）
    - **これらすべての条件を維持したページネーション（1ページ5件表示）**
3. **視覚的な動的UI**：
    - 期限に応じたアラート色変化（今日＝赤、3日以内＝黄）
    - 重要度に応じたバッジ表示（高・中・低）
    - 完了タスクのグレーアウト＆打ち消し線（完了ボタンの非表示化）
4. **タスク編集・削除機能**：
    - 編集画面でのバリデーションおよび重要度の更新連動
    - 一括削除機能 / `@PathVariable` を用いた個別削除機能
5. **入力値バリデーション**：
    - 新規登録・編集時、エラー箇所にBootstrapの `is-invalid` を用いた赤文字警告を表示

## 🛠️ 技術スタック
- **バックエンド**: Java 21 / Spring Boot 3.x
- **フロントエンド**: HTML5 / Thymeleaf / Bootstrap 5
- **データベース**:
    - ローカル環境: H2 Database（インメモリ）
    - 本番環境: Neon DB (PostgreSQL)
- **インフラ / ホスティング**: Render

## 💻 ローカル環境での起動方法

### 前提条件
- Java 21 以上がインストールされていること

### 起動手順
1. 本リポジトリをクローンします。
   ```bash
   git clone https://github.com/Takeyuki-Ishii/KijiList
   ```
2. プロジェクトのルートディレクトリに移動します。
   ```bash
   cd KijiList
   ```
3. アプリケーションを起動します（Mavenの場合）。
   ```bash
   ./mvnw spring-boot:run
   ```
4. ブラウザで以下のURLを開きます。
    - `http://localhost:8080/login`
