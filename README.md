## 📋 システム概要
本システムは、タスクの「期限」と「重要度」を一目で把握し、タスクの遅延ややり残しを防ぐためのWebアプリケーションです。
一般的なタスク管理機能に加え、プログラミング実務で求められる**「複雑な検索・フィルタリングの条件維持」**や**「ユーザーを迷わせない動的UI」**を徹底して作り込みました。

## 🎯 制作目的・背景

### 1. 想定利用者
*   複数のプロジェクトや締切を抱え、タスクの優先順位付けに悩むビジネスパーソン
*   「やること」が多く、期限直前になって慌ててしまう個人ユーザー

### 2. 解決したい課題
*   **「締切の忘却」の防止**: 期限が迫っているタスクが埋もれてしまい、破綻するリスク。
*   **「優先順位」の混乱**: どれから手をつければいいか分からなくなり、効率が低下する問題。
*   **「操作ストレス」の軽減**: 検索やページを切り替えるたびに条件がリセットされ、何度も再入力させられるストレス。

---
## 🌟 本システムのこだわり（アピールポイント）
### 1. 「検索 × ソート × フィルター × ページネーション」の完全連動
*   **仕様**: タスク名検索（部分一致）、状態絞り込み（すべて/未完了/完了）、ソート（期限順/重要度順）のどの操作を掛け合わせても、URLパラメータが完全に維持されます。
*   **こだわり**: 2ページ目で「完了ボタン」を押したり、編集画面でバリデーションエラーが発生したりしても、ユーザーが直前に見ていたページや検索条件を失わない、ストレスフリーな設計を追求しました。

### 2. 直感的に状況を把握できる「動的UI」
*   **期限の可視化**: タスクの期限に応じて、背景色や文字色が動的に変化します（当日＝赤、3日以内＝黄）。
*   **重要度バッジ**: 高・中・低の重要度を色付きのBootstrapバッジで表現し、優先度を一瞥できるようにしました。
*   **完了状態の表現**: 完了したタスクは自動的に文字がグレーアウトされ、打ち消し線が引かれます。また、二重操作を防ぐため「完了ボタン」は非表示になります。

### 3. 堅牢な入力値バリデーション
*   タスク登録および編集画面（`task-edit.html`）の両方にバリデーションを実装。
*   エラー発生時は、Bootstrapの`is-invalid`クラスを動的に適用し、対象の入力フォームを赤枠・赤文字で強調してユーザーにエラー内容を優しく通知します。

### 4. 開発効率を意識した環境切り替え
*   ローカル開発時は起動が高速な「H2 Database」を使用し、本番（Render）環境では「Neon DB（PostgreSQL）」へと自動で接続が切り替わるよう環境変数を制御しています。

## 🚀 主な機能
1. **タスク一覧表示**：期限が近い順 / 重要度順に自動ソート
2. **高度な条件絞り込み＆検索**：
    - キーワード検索（タスク名の部分一致）
    - 完了状態フィルター（すべて / 未完了のみ / 完了のみ）
    - ソート切り替え（期限順 / 重要度順）
    - **これらすべての条件を維持したページネーション（1ページ5件表示）**
3. **視覚的な動的UI**：
    - 期限に応じたアラート色変化（今日＝赤、3日以内＝黄）
    - 重要度に応じたバッジ表示（高・中・低）
    - 完了タスクのグレーアウト＆打ち消し線（完了ボタンの非表示化）
4. **タスク編集・削除機能**：
    - 編集画面でのバリデーションおよび重要度の更新連動
    - 一括削除機能 / `@PathVariable` を用いた個別削除機能
5. **入力値バリデーション**：
    - 新規登録・編集時、エラー箇所にBootstrapの `is-invalid` を用いた赤文字警告を表示

## 🛠️ 技術スタック
- **バックエンド**: Java 21 / Spring Boot 3.x
- **フロントエンド**: HTML5 / Thymeleaf / Bootstrap 5
- **データベース**:
    - ローカル環境: H2 Database（インメモリ）
    - 本番環境: Neon DB (PostgreSQL)
- **インフラ / ホスティング**: Render

## 💻 ローカル環境での起動方法

### 前提条件
- Java 21 以上がインストールされていること

### 起動手順
1. 本リポジトリをクローンします。
   ```bash
   git clone https://github.com/Takeyuki-Ishii/KijiList
   ```
2. プロジェクトのルートディレクトリに移動します。
   ```bash
   cd KijiList
   ```
3. アプリケーションを起動します（Mavenの場合）。
   ```bash
   ./mvnw spring-boot:run
   ```
4. ブラウザで以下のURLを開きます。
    - `http://localhost:8080/login`
